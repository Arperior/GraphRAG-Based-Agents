# ======================= GraphRAG Extract Graph Prompt (Optimized) =======================

Goal:
Identify entities and relationships from the text.
Output MUST be valid JSON.

Rules:
1. Entities: "description" must be VERY SHORT (Max 8 words).
2. Relations: "evidence" must be a SHORT snippet (Max 12 words).
3. Do NOT quote full sentences.
4. Return ONLY valid JSON.

Format:
{
  "entities": [
    {"name": "Delhi", "type": "GEO", "description": "Capital of India"},
    {"name": "Modi", "type": "PERSON", "description": "Prime Minister"}
  ],
  "relations": [
    {"source": "Delhi", "target": "Modi", "relation": "LOCATED_IN", "evidence": "works in Delhi", "confidence": 1.0}
  ]
}

Text:
{input_text}
