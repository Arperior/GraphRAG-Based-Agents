1. Make a new folder 
2. Have python 3.12.5 installed
3. run : pip install uv
4. Create venv using : uv venv --python 3.12
5. run : .venv\Scripts\Activate.ps1
6. If security error run : Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
7. Once it shows name of venv like (venv) then :
    - IN CASE OF PIP ERROR: python -m ensurepip --upgrade
    - uv pip install graphrag openai spacy nltk python-dotenv poethepoet requests python-Levenshtein PyPDF2 tiktoken google-genai streamlit llama-cpp-python huggingface_hub pillow
    - python -m spacy download en_core_web_md
    * NOTE: If you have an NVIDIA GPU, install llama-cpp-python with CUDA support for faster processing:
      $env:CMAKE_ARGS="-DLLAMA_CUDA=on"; pip install llama-cpp-python --upgrade --force-reinstall --no-cache-dir
8. Once done, execute order 66.
9. Install JDK 21 :- https://docs.oracle.com/en/java/javase/24/install/installation-jdk-microsoft-windows-platforms.html#GUID-A7E27B90-A28D-4237-9383-A58B416071CA
10. Download Neo4j :- https://neo4j.com/docs/operations-manual/current/installation/windows/
11. Install CE(not as service) as listed in the installation guide.
12. Download APOC JAR from GitHub (matching Neo4j version).
13. Copy APOC JAR to ...\Neo4jDesktop2\Data\dbmss\<dbms-id>\plugins\
14. Edit neo4j.conf → add:
    -dbms.security.procedures.unrestricted=apoc.*,gds.*
    -dbms.security.procedures.allowlist=apoc.*,gds.*
    -apoc.import.file.enabled=true
    -apoc.export.file.enabled=true
    -apoc.trigger.enabled=true
    -dbms.default_database=neo4j
15. Restart Neo4j Desktop.
16. Open Neo4j Browser → Run: RETURN apoc.version();
    Run these commands to setup schema:
        // Unique user IDs
        CREATE CONSTRAINT unique_user IF NOT EXISTS
        FOR (u:User) REQUIRE u.id IS UNIQUE;
        // Query timestamp uniqueness
        CREATE CONSTRAINT unique_query_created IF NOT EXISTS
        FOR (q:Query) REQUIRE q.created IS UNIQUE;
        // Answer timestamp uniqueness
        CREATE CONSTRAINT unique_answer_created IF NOT EXISTS
        FOR (a:Answer) REQUIRE a.created IS UNIQUE;
        // Entity name unique 
        CREATE CONSTRAINT unique_entity_name IF NOT EXISTS
        FOR (e:Entity) REQUIRE e.name IS UNIQUE;
        // Chunk IDs unique
        CREATE CONSTRAINT unique_chunk_id IF NOT EXISTS
        FOR (c:Chunk) REQUIRE c.id IS UNIQUE;
        // Community id uniqueness
        CREATE CONSTRAINT community_id_unique IF NOT EXISTS
        FOR (com:Community) REQUIRE com.id IS UNIQUE;
        CREATE INDEX user_last_seen_idx IF NOT EXISTS
        FOR (u:User) ON (u.last_seen);
17. Download Local Models (Text & Vision) to C:\models:

    - OPTION A (Recommended): Run the automated script provided:
        python download_models_v2.py
    
    - OPTION B (Manual Download):

           - Save to: C:\models\mistral-7b-instruct-v0.1.Q4_K_M.gguf
        
        2. Vision Model (LLaVA v1.5):
           - URL: https://huggingface.co/jartine/llava-v1.5-7B-GGUF
           - File: llava-v1.5-7b-Q4_K.gguf
           - Save to: C:\models\llava-v1.5-7b-Q4_K.gguf
        
        3. Vision Projector (LLaVA Clip):
           - URL: https://huggingface.co/jartine/llava-v1.5-7B-GGUF

18. Create .env in project root with:
    -NEO4J_URI=bolt://localhost:7687
    -NEO4J_USER=neo4j
    -NEO4J_PASSWORD=your_password
    -GEMINI_API_KEY=your_gemini_api_key (Optional now for Image, still used for Chat if enabled)
    # Central Model Path
    -LOCAL_LLM_MODEL=C:\models
    # Text Model
    -LOCAL_LLM_FILE=mistral-7b-instruct-v0.1.Q4_K_M.gguf
    # Vision Models
    -LOCAL_LLAVA_MODEL=C:\models\llava-v1.5-7b-Q4_K.gguf
    -LOCAL_LLAVA_CLIP=C:\models\mmproj-model-f16.gguf
    # App Settings
    -LEIDEN_RESOLUTION=1.0
    -RETRIEVAL_SEARCH_LIMIT=10
    -NEO4J_QUERY_LIMIT=100
19. Test APOC in Python: python -m pipeline.neo4j_client
20. Run mistral test: testing.py
